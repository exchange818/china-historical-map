# 历史世界地图 · 中原与周边三千年

以中原王朝为轴心的古代东亚世界交互地图。单个自包含 HTML 文件，无任何外部依赖，离线可用。

## 内容

- 时间轴跨 前 1046 — 1912，可拖动滑块，也可直接输入年代（负数代表公元前）
- 中原 18 个朝代：随年代切换的帝王在位序列、当朝名臣、重大事件
- 周边 91 个政权：按 东北 / 北方草原 / 西域 / 西南 / 海路 / 远西 六类着色，起止年一到即淡入淡出
- 今日中国省级界线以半透明暗影叠加，作为古今对照
- 点击任一政权的色块或中原疆域，右侧展开其存续、今地、与中原关系、人物与事件

## 说明

- 色块表示势力范围示意，不是精确疆界
- 省级界线取自公开地理数据并作抽稀，底图海岸线依现代轮廓简化
- 政权名称取其时通行称谓，存续年份多为史家通行的约数
